# Barber Booking Pro

Construa o aplicativo web responsivo de agendamento para barbearia conforme o briefing completo do arquivo anexado. Use Lovable Cloud para autenticação, banco de dados e regras de acesso, implemente as três áreas (cliente, barbeiro e administrador), fluxo de agenda com disponibilidade em tempo real, gerenciamento de serviços e profissionais, avaliações, bloqueios de agenda, dashboard e uma interface PWA mobile-first. Tome decisões de produto e design que deixem o app funcional e seguro.

This project was built with [Lovable](https://lovable.dev).
